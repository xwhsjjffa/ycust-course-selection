教务选课助手 · 使用说明
Windows 桌面版 / Android 手机版  ·  v1.2  ·  按学分自动抢：2 分 → 1 分 → 0.5 分
本软件完全免费。任何人向你收费、售卖、或收钱“代抢”，都是骗子。

一、怎么用（4 步）
1. 双击 教务选课助手.exe（手机则安装 教务选课助手.apk，允许“安装未知应用”）。
2. 填学号、密码（密码不保存，每次输入）。
3. 设门数：2 分 [1] 门、1 分 [2] 门、0.5 分 [4] 门 —— 按需改，填 0 表示不抢这档。
4. 点「▶ 开始 Let's go」，下面日志会滚动；抢到或暂停都会弹窗告诉你结果。
二、界面
 
区域	作用
① 登录	学号 / 密码；勾「显示」可看密码
② 抢课计划	三档门数、轮次链接；「高级选项 ▸」里是开始时间、最长运行、重试间隔（1~5 秒）、调试
③ 开始 / 暂停	开始抢课；暂停后弹窗汇总本次结果
④ 运行日志	实时输出：登录、候选数量、抢到/没抢到、N 秒后重试
三、规则
•	按学分抢，不看课程名：2 分档只抢 2 学分课，1 分档只抢 1 学分课，0.5 分档只抢 0.5 学分课。
•	顺序 2 分 → 1 分 → 0.5 分，同档先抢剩余名额少的；各档抢满即停。
•	没抢到就按「重试间隔」反复刷新（默认 5 秒，可调 1~5 秒）。
•	系统返回“选课学分不能超过 X 学分”时，程序立即停止并弹窗，不会白刷。
四、会弹什么窗
情形	弹窗内容
抢到一门	「抢到课了」：课程名 + 几分 + 当前进度
暂停 / 时长到	「已暂停」：进度 + 本次抢到的每一门；没抢到会写明
全部抢满	「抢课完成」：总学分 + 课程清单
达到学分上限	「选课受限」：系统原话 + 提示先退课
连不上网	「连接失败：服务器未连接上，请重试。」
五、注意事项
•	你的公选课已选满 2 学分（审美分析、大话机器人），不退课的话再抢会被系统拒绝。
•	换轮次时，把浏览器里的 xsxk_index?jx0502zbid=... 链接粘到「轮次链接」，留空则自动查找。
•	日志在 exe 同目录 grab_log.txt；点「打开日志文件」可直接看。
•	仅用本人账号，遵守学校规定；选课结果以教务系统为准。
